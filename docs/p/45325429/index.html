بافت کبریتی ظریف و ایستایی عالی روی تن؛ ساده، شیک و مناسب استفاده هر روز.

  • دوخت تمیز صنعتی، یقه کشباف مقاوم که بعد از شستشو باز نمی‌شود و پارچه‌ای که روی تن خوش می‌نشیند.
  • سایزبندی XL تا 3XL.
  • ۲ رنگ موجود: کرمی، طوسی روشن.
  • مناسب برای استفاده روزمره، دانشگاه، سفر و دورهمی.

نکته سایز: اگر بین دو سایز هستید، برای فرم اورسایز سایز بزرگ‌تر و برای فرم معمولی سایز همیشگی خود را بردارید.

نگهداری: در آب سرد یا ولرم (حداکثر ۳۰ درجه) و پشت‌ورو بشویید؛ برای حفظ چاپ، روی طرح اتو نکنید.
