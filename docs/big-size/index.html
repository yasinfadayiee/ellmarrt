لباس سایز بزرگ مردانه تا چه سایزی دارید؟

در المارت تیشرت تا 5XL، شلوار اسلش و شلوارک تا 6XL و هودی و دورس تا 3XL موجود است.

سایز 4XL برای چه وزنی مناسب است؟

به طور معمول 4XL برای وزن حدود ۱۰۵ تا ۱۱۸ کیلوگرم و 5XL برای ۱۱۸ تا ۱۳۲ کیلوگرم مناسب است؛ برای دقت بیشتر از سایزیاب استفاده کنید.

قد شلوارهای سایز بزرگ چقدر است؟

قد شلوارهای اسلش سایز بزرگ المارت بین ۱۰۵ تا ۱۱۰ سانتی‌متر است تا برای افراد قدبلند هم مناسب باشد.

تولیدی و پخش پوشاک مردانه المارت؛ بیش از ۶۰ سال فعالیت در بازار بزرگ (سرپوشیده) تبریز. پوشاک روزمره مردانه با کیفیت بازار، قیمت منصفانه و سایزبندی واقعی تا 6XL.
